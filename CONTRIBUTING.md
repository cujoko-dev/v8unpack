# Участие в разработке

Перед pull request соберите проект и запустите `ctest --preset windows-x64`.
Изменения формата контейнера должны сопровождаться интеграционным тестом.
Не добавляйте в репозиторий конфигурации 1С с закрытыми или персональными
данными — используйте игнорируемый каталог `test/local-fixtures/`.

Старайтесь сохранять совместимость существующих ключей CLI. Новые публичные
команды и изменения поведения следует описывать в README.
