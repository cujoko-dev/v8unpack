# Безопасность

Не открывайте публичный issue для уязвимости, если описание или образец файла
позволяют воспроизвести эксплуатацию. Отправьте владельцу репозитория приватное
сообщение через GitHub Security Advisories.

Поддерживается последняя опубликованная версия. Контейнеры считаются
недоверенным вводом; особенно важны сообщения о выходе за пределы каталога,
зависаниях и неконтролируемом потреблении памяти.
